---
title: Проценты в abs()
icon: lucide/newspaper
---

> Sass исторически поддерживал функцию `abs()`. После того как CSS начал поддерживать вычисления в Values and Units Level 4, нам пришлось обойти проблему обратной совместимости. Однако для функции `abs()` у нас есть проблема совместимости с единицей `%`.

Глобальная функция `abs()` в Sass поддерживала единицу `%` как входной параметр и разрешала функцию `abs()` до разрешения значения `%`. Например, если входным значением было `abs(10%)`, функция вернёт `10%`. В результате, если значение `10%` представляло `-50px`, функция вернёт `-50px`.

Однако функция `abs()` в CSS разрешает `%` до разрешения самой функции. Поэтому если значение `10%` представляло `-50px`, `abs(10%)` вернёт `-10%`, что в браузере будет `50px`.

По этой причине мы устареваем глобальную функцию `abs()` с процентами. Чтобы сохранить текущее поведение, используйте `math.abs()` вместо неё.
