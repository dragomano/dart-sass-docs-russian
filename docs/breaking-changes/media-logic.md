> Sass добавил поддержку спецификации CSS Media Queries Level 4. Изначально это конфликтовало с некоторым специфичным для Sass синтаксисом, поэтому этот синтаксис был объявлен устаревшим и теперь интерпретируется в соответствии со стандартом CSS.

Поскольку Sass поддерживает практически любое выражение Sass в скобочных условиях медиазапросов, было несколько конструкций, значение которых изменилось при добавлении полной поддержки Media Queries Level 4. В частности:

- `@media (not (foo))` исторически интерпретировалось Sass как `@media (#{not (foo)})` и, таким образом, компилировалось в `@media (false)`.

- `@media ((foo) and (bar))` и `@media ((foo) or (bar))` аналогично интерпретировались как логические операторы SassScript, компилируясь в `@media (bar)` и `@media (foo)` соответственно.

К счастью, на практике это встречалось очень редко.
