> До Dart Sass 1.76.0 имена функций и миксинов могли быть любым допустимым CSS-идентификатором, но идентификаторы, начинающиеся с `--`, теперь устарели.

В общем случае Sass разрешает использовать любой допустимый CSS-идентификатор для любого определения Sass. Это включает идентификаторы, начинающиеся с `--`, которые пользователи могут лучше всего знать в контексте [CSS пользовательских свойств](https://www.w3.org/TR/css-variables-1/). Однако рабочая группа CSS [серьёзно рассматривает](https://github.com/w3c/csswg-drafts/issues/9350) добавление встроенной поддержки функций и миксинов непосредственно в CSS, вероятно, используя at-правила `@mixin` и `@function`, как в Sass.

Это означает, что Sass, чтобы сохранить свой основной принцип проектирования — совместимость с CSS, при этом поддерживая функции и миксины Sass на этапе сборки, должен уметь различать CSS и Sass объявления, использующие одинаковые имена at-правил. К счастью, хотя детали синтаксиса, который CSS будет использовать для функций и миксинов, всё ещё очень неопределённы, один момент кажется бесспорным: использование идентификаторов, похожих на пользовательские свойства, начинающихся с `--`, для имён CSS миксинов и функций.

Это позволит Sass различать обычные CSS функции и миксины как те, что начинаются с `--`. Но чтобы это работало, сначала мы должны запретить Sass функциям и миксинам использовать этот префикс.

## Переходный период {#transition-period}

### Фаза 1: Устаревание {#phase-1-deprecation}

Между Dart Sass 1.76.0 и Dart Sass 1.94.0 Dart Sass продолжал разрешать функции и миксины, имена которых начинаются с `--`. Однако он выдавал предупреждение об устаревании с именем `css-function-mixin`.

### Фаза 2: Обычные CSS-функции {#phase-2-plain-css-functions}

Dart Sass 1.94.0 добавил поддержку обычных CSS-функций, поскольку они появились в Chrome незадолго до этого. Любая функция, имя которой начинается с `--`, теперь парсится как обычное CSS at-правило, а её свойство `result` парсится так же, как значение пользовательского свойства.

На фазе 2 миксины, имена которых начинаются с `--`, были повышены с устареваний до ошибок.
