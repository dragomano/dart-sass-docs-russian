---
title: Дублирующиеся флаги переменных
icon: lucide/newspaper
---

> Переменные будут разрешать только один флаг `!global` или `!default`. Дублирующиеся флаги никогда не имели дополнительного эффекта, это просто обеспечивает большую согласованность таблиц стилей.

## Фаза 1 {#phase-1}

Начиная с Dart Sass 2.0.0, если одно объявление переменной содержит более одного флага `!global` или `!default`, это будет синтаксической ошибкой. Это означает, что `$var: value !default !default` будет запрещено. `$var: value !global !default` по-прежнему будет разрешено.

## Переходный период {#transition-period}

До выпуска Dart Sass 2.0.0 множественные копии флага просто выдают предупреждения об устаревании.
